# ```Netflix Data Analysis```

#### Business Scope

- Netflix Management wants a comprehensive analysis of it's content catalog:

        Key Objectives:
        - Country-wise content production
        - Popular Directors
        - Content Ratings
        - Genre Popularity


Dataset:netflix_titles.csv

### ```Objectives:```

##### 1. Data Understanding

        - Load dataset using Pandas
        - Descriptive Statistical on dataset
        - List out unique count for columns

##### 2. Data Cleaning

        - Find Duplicates
        - Remove Duplicates
        - Check for Null values and handle them buy imputation.
        - Drop null values which are not making any benefits to analysis.

##### 3. Feature Engineering

        - Spliting dataframe into two type handling
        - Extracting year, month name, content age, movie duration.

##### 4. Exploratory Data Analysis [EDA]:

- understanding the data statistically and visualization.

        Anomaly detection:
        - High & low volumes of shows added by netflix.
        - Outliers using Z-score
        - visualize monthly trends with outliers.
