### Student Grade Calculator

- This Mini Project demonstrate the calculation of student marks with percenatage, gpa and based on marks and finalizing the leaderboard among all students.

- Topics cover to implement are
 
    - User Inputs
    - Loops
    - Lists
    - Functions
    - Conditional statements
    - get() method usage.

##### Features:

    - Add student information
    - Display student information
    - Leaderboard
    - Exit
